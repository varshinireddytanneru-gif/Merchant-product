# Merchant and Product Management System

## 📌 Project Description

The Merchant and Product Management System is a web-based application designed to manage merchant details and their associated products efficiently. It provides an organized platform to perform CRUD (Create, Read, Update, Delete) operations on merchant and product information.

The application helps maintain merchant records, manage product details, and establish relationships between merchants and their products.

## 🚀 Features

### Merchant Management
- Add new merchants.
- View all merchant details.
- Update merchant information.
- Delete merchant records.
- Manage merchant information efficiently.

### Product Management
- Add new products.
- View product details.
- Update product information.
- Delete products.
- Associate products with merchants.
